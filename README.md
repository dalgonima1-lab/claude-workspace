# claude-workspace

Claude Code와 함께 사용하는 개인 작업 공간입니다.

## 폴더 구조

```
claude-workspace/
├── prompts/   # 자주 쓰는 프롬프트 모음
├── scripts/   # 자동화 스크립트
└── notes/     # 메모 및 기록
```

## 시작하기

```powershell
cd C:\Users\Wonje\projects\claude-workspace
claude
```

## 스크립트 사용법

새 프롬프트 파일 빠르게 만들기:

```powershell
.\scripts\새-프롬프트-만들기.ps1 "번역-요청"
```
