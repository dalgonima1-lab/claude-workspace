## 1. 한 줄 요약

갤럭시 폴드 8에서 쓰는 개인용 안드로이드 앱. 갤럭시 AI 통화 요약과 문자·카톡 내용을 공유 버튼으로 넘기면,
AI가 사업 관련 내용만 골라 거래처별로 정리하고, 약속과 기한을 삼성 캘린더 일정·할 일·리마인더로 자동 등록한다.

임시 앱 이름: **사업 비서**

---

## 2. 대화 흐름 요약

### Q1. 갤럭시 폴드 8용 나만의 앱을 만들 수 있나?
- 가능. 세 가지 방식 중 선택.
  - 웹앱(PWA): 가장 빠름, 설치 없음, Vercel로 배포 가능. 기기 기능 접근은 제한적.
  - **네이티브 안드로이드(Kotlin + Jetpack Compose)**: 공유 수신, 캘린더 쓰기, 알림, 위젯 등 기기 기능에 적합. → **이 방식으로 결정**
  - 크로스플랫폼(Flutter/React Native): 아이폰 버전까지 생각하면 유리.
- 폴드 특화 포인트: 커버 화면과 펼친 화면의 비율 차이에 따른 반응형 레이아웃, 플렉스 모드(반 접힘) 상하 분할.
- 제약: 클라우드 세션에서는 폰에 직접 설치·화면 확인 불가. APK 또는 배포 주소를 전달하면 사용자가 직접 설치해 확인.

### Q2. 갤럭시 AI 통화 요약에서 사업 내용을 자동 정리하고 일정 관리까지 되나?
- 가능. 단, 갤럭시 AI 요약은 다른 앱이 직접 읽어갈 공개 API가 없음.
- **방식 1 (반자동, 추천 시작점)**: 통화 후 요약 화면에서 "공유" → 우리 앱 선택 → 이후 전부 자동.
- **방식 2 (완전 자동)**: 통화 녹음 파일 폴더를 감시 → 음성 인식(STT) → AI 정리. 비용·배터리·백그라운드 권한 부담. 방식 1 이후 확장.
- 공통 기능: 사업 여부 판별(AI 판단 + 연락처 "거래처" 그룹은 무조건 사업), 일정 등록 전 확인 카드, 거래처별 기록.
- 캘린더: 안드로이드 공용 캘린더(CalendarContract)에 쓰면 삼성 캘린더에 반영됨.
- 비용: 통화 1건당 몇 원~몇십 원 수준.

### Q3. 삼성 캘린더 사용 확정. API 키 발급 절차와 유료 여부
- **사용 캘린더: 삼성 캘린더** (확정)
- Claude API는 종량제 유료. Claude Pro 구독과 별개 계정·별개 결제.
- 예상 비용 (통화 요약 텍스트 기준):

  | 모델 | 통화 1건 | 월 100통 |
  |---|---|---|
  | Claude Opus 5.5 (정확도 우선) | 약 30원 | 약 3,000원 |
  | Claude Haiku 5.5 (저렴) | 약 1원 미만 | 약 100원 |

- 처음엔 Opus 5.5로 정확도 확인 → 안정되면 Haiku 5.5로 비용 절감.

### Q4. 코덱스(OpenAI)는 API를 공짜로 주지 않나?
- 아님. 구독과 API는 분리. ChatGPT Plus에 포함된 건 코덱스 "도구" 사용량이고, 프로그램이 호출하는 API 키 사용은 별도 과금.
- 구독 계정을 앱 뒤에 끼워 넣는 우회는 약관 위반이며 24시간 자동 앱에 부적합.

### Q5. 코덱스에 100달러짜리 API가 있다던데?
- "코덱스 API"가 아니라 **ChatGPT Pro 구독에 포함된 월 API 크레딧**. (2026-10-28경 시작, 2차 매체 기준)
  - Pro 100달러 → 월 100달러 크레딧, Pro 200달러 → 월 200달러 크레딧.
- 이 크레딧은 일반 API 호출(우리 앱)에 사용 가능. **코덱스 API 키 사용에는 불가**, ChatGPT/코덱스 구독 한도도 안 늘림.
- 공짜가 아니라 월 100달러 구독에 100달러어치를 얹어 주는 구조. Plus(20달러)는 해당 없음.
- 실제 지급 여부는 OpenAI 계정 Billing 화면에서 확인 필요.

### Q6. 클로드에는 그런 기능 없나?
- 있음. 2026-10-07부터 **Claude Max·Team 요금제에 월 API 크레딧 포함** (2차 매체 기준).

  | 요금제 | 월 요금 | 포함 API 크레딧 |
  |---|---|---|
  | Pro | 20달러 | 없음 |
  | Max 5x | 100달러 | 매달 100달러 |
  | Max 20x (Ultra로 명칭 변경) | 200달러 | 매달 200달러 |

- 구독 7일 후 Claude Console 조직을 연결하면 매달 지급. API·콘솔 플레이그라운드·Managed Agents·Agent SDK에 사용 가능.
- Claude Code(터미널/IDE/웹) 한도는 안 늘림. 미사용분 이월 없음. Pro는 콘솔 API 미포함.
- 결론: Max 구독 중이면 추가 비용 0. 아니면 콘솔에 5달러 충전이 가장 저렴. 앱 하나 때문에 Max 구독은 불필요.

### Q7. API 키 어디서 받나?
**Claude (기본 추천)**
1. platform.claude.com 로그인 (Claude 앱과 같은 이메일)
2. 조직 이름 입력 → 콘솔 진입
3. Max 구독자: 콘솔 안내에 따라 계정 연결 → 크레딧 지급 / 아니면 Billing에서 카드 등록 후 5달러 충전 (자동 충전 OFF)
4. API Keys → Create Key → 이름 "통화정리앱"
5. `sk-ant-` 로 시작하는 키 복사·보관 (한 번만 표시)

**OpenAI (ChatGPT Pro 크레딧 사용 시)**
1. platform.openai.com 로그인
2. Billing에서 Pro 크레딧 입금 확인
3. API keys → Create new secret key
4. `sk-` 로 시작하는 키 복사·보관

**키 보관 원칙**
- 폰 앱 안에 키를 직접 넣지 않는다 (APK에서 추출 가능).
- **Vercel에 작은 중계 서버**를 두고 키는 거기 환경 변수에만 저장. 폰 앱은 중계 서버와만 통신.
- 개인 사용 규모는 Vercel 무료 플랜으로 충분.
- 키는 채팅에 붙여넣지 않는다. 환경 변수 입력 단계에서 안전하게 넣는다.

## 3. 기능 목록 (★ = 추천)

### 3-1. 정보가 들어오는 통로 (입력)
- ★ **통화 요약 공유 수신**: 갤럭시 AI 요약을 공유 버튼으로 넘기면 자동 분석. 핵심 기능.
- ★ **문자·카톡 내용 공유**: 거래처 문자/카톡(견적 요청, 납기 변경, 입금 안내)을 같은 공유 버튼으로 처리.
- ★ **명함 촬영**: 이름·회사·직함·연락처 인식 → 거래처 등록 + 폰 연락처 저장.
- ★ **영수증·세금계산서 촬영**: 금액·날짜·상호·사업자번호 인식 → 지출 기록. 월말 정산·세무사 전달 자료 자동 생성.
- **은행 입출금 문자 자동 읽기**: 문자 수신 권한으로 입금 감지 → 미수금 자동 대조. 완전 자동이지만 민감 권한.
- **음성 메모**: 말로 남기면 텍스트 변환 → 할 일·일정 정리.
- **이메일 연동**: 지메일/네이버 메일의 거래처 메일 처리. 설정 복잡, 2단계 이후.
- **현장 방문 기록**: 거래처 주소 근처 도착 시 방문 기록 제안. 외근 많은 업종용.

### 3-2. 정리하고 관리하는 기능
- ★ **거래처별 타임라인**: 통화·문자·메일·방문·결제를 거래처 하나에 시간순 집계. 폴드 펼친 화면: 좌 목록 / 우 타임라인.
- ★ **할 일·일정 자동 추출**: 날짜 있으면 삼성 캘린더 일정, 없으면 할 일. 등록 전 확인 카드.
- ★ **후속 조치 리마인더**: "견적 보내기로 함", "다음 주 다시 연락" 등을 잡아 기한 전날 알림.
- ★ **미수금·지급 관리**: 금액과 결제 조건 추출 → 받을 돈/줄 돈 목록, 기한 경과 알림.
- **견적·계약 진행 단계**: 문의→견적→협의→계약→납품→수금 단계 관리.
- **검색과 질문**: "지난달 김 부장이랑 단가 얼마로 얘기했지?" 자연어 질의.
- **민감 통화 제외**: 특정 연락처/키워드는 AI 전송 없이 기기에만 저장.

### 3-3. 밖으로 내보내는 기능 (출력)
- ★ **아침 브리핑**: 오늘 일정, 기한 임박 할 일, 오래 연락 안 한 거래처. 알림 또는 카카오톡 "나에게 보내기".
- ★ **답장·견적 초안 작성**: 통화 정리 직후 확인 문자 초안 생성 → 수정 후 전송.
- **주간·월간 보고서**: 거래처 진행 현황, 수입·지출, 미수금 → PDF/엑셀.
- **홈 화면 위젯**: 커버 화면에 오늘 할 일·다음 일정. 펼치지 않아도 확인.
- **백업·PC 열람**: 구글 드라이브 자동 백업, PC 브라우저에서 동일 데이터 열람.

### 3-4. 추천 개발 순서
1. **1단계**: 통화·문자 공유 수신, 거래처 타임라인, 일정·할 일 추출, 후속 조치 리마인더
   → 이것만으로 "정리 + 일정 관리" 완성
2. **2단계**: 명함·영수증 촬영, 미수금 관리, 아침 브리핑, 답장 초안
3. **3단계**: 입금 문자 자동 대조, 자연어 검색, 보고서, 위젯, 메일 연동

### 3-5. 제약 사항
- 갤럭시 AI 요약과 카톡 대화는 다른 앱이 몰래 읽을 수 없음 → 공유 버튼 한 번 필수. 완전 자동은 통화 녹음 파일 감시로 확장.
- 입금 문자 읽기·위치 기록은 민감 권한 → 개인 사용 전용, 플레이스토어 공개 배포 어려움.
- 통화 내용이 AI API로 전송됨 → 민감 통화 제외 옵션 필수.
